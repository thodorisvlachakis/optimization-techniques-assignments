# Optimization Techniques – Portfolio

Welcome! This repository serves as a **central portfolio** for all my assignments from the:

**Optimization Techniques course**

It collects and organizes the work developed throughout the course, covering fundamental concepts of numerical optimization, including one-dimensional search methods, unconstrained multivariable optimization, and constrained optimization techniques.

Each assignment focuses on a different class of optimization problems, progressively building a deeper understanding of algorithmic behavior, convergence, and practical implementation.

---

## Assignments

### 1. [Assignment 1 – One-Dimensional Optimization](https://github.com/thodorisvlachakis/one-dimensional-optimization)
**Topics:**
- Unimodal function minimization
- Bracketing methods
- Golden Section Method
- Fibonacci Search Method
- Interval reduction techniques

---

### 2. [Assignment 2 – Unconstrained Multivariable Optimization](https://github.com/thodorisvlachakis/unconstrained-multivariable-optimization)
**Topics:**
- Steepest Descent Method
- Newton’s Method
- Levenberg–Marquardt Method
- Step size strategies
    - Constant step size
    - Armijo rule
    - Exact line search
- Convergence speed and stability analysis

---

### 3. [Assignment 3 – Steepest Descent Projection Method: Constrained Optimization](https://github.com/thodorisvlachakis/steepest-descent-projection-method)
**Topics:**
- Steepest Descent Method with constant step size
- Projection technique for handling constraints
- Projected Steepest Descent Method
- Feasible set enforcement
- Effect of step size parameters on convergence
- Behavior under feasible and non-feasible initial conditions
